🧠 Prompt for Coding LLM

Role: You are a senior full-stack engineer specializing in AI dashboard interfaces and RAG system management UIs.
You are tasked with building a complete frontend application for an enterprise-grade RAG (Retrieval-Augmented Generation) system that integrates with a FastAPI backend.

---

🚀 Project Overview

You are building the frontend dashboard for a commercial RAG (Retrieval-Augmented Generation) system named Nexus RAG.
The backend is built with FastAPI and exposes REST endpoints for document management, embeddings, retrieval settings, fine-tuning, and monitoring.
The frontend will serve data scientists, AI engineers, and enterprise users who want to manage their company’s private knowledge base and RAG behavior.

🧱 Core Dashboard Sections

1. 📚 Document Management
- Upload Documents
  - Upload PDFs, text, or markdown files.
  - Send to /api/documents/upload.
  - Auto-split into chunks and embed via backend.
- Document Viewer
  - Table listing all uploaded docs with name, date, size, and vector count.
  - Buttons for “View Chunks”, “Re-Embed”, “Delete”.
- Grouping
  - Create logical groups or projects (e.g., “HR Policies”, “Engineering Docs”).
  - Assign documents to groups.
  - Enable filtering by group in queries.

2. 🧠 Embedding & Vector Store
- Database Integration
  - Display current vector DB (Postgres + pgvector).
  - Show counts: number of chunks, total embeddings, dimensionality.
- Maintenance
  - Button to re-index or optimize embeddings.
  - Show last update time and health status.
- Preview
  - Fetch sample vectors and similarity search preview.

3. 🔍 Query Interface
- Ask a Question
  - Textbox to input a natural language query.
  - Dropdown to select model (local LLMs or API).
  - Adjust parameters:
    - top_k
    - chunk_size
    - chunk_overlap
    - temperature
  - Display response and retrieved context side by side.
- Session History
  - Maintain chat-style history for the user session.

4. ⚙️ RAG Parameter Controls
- Global Settings
  - Set defaults for retrieval and generation parameters.
  - Toggle caching, reranking, or hybrid search.
- Chunking Configuration
  - Adjust chunk size and overlap values.
  - Preview how a document is split.

5. 🧩 Function Calls / Tools
- Add and manage external functions the RAG system can call.
- Define:
  - Function name
  - Description
  - Input schema (JSON)
  - Endpoint URL
- Toggle availability of each function.
- Save configuration to backend.

6. 🧬 Fine-Tuning Setup
- Upload datasets for fine-tuning.
- Display dataset stats (rows, tokens, format).
- Integrate upload to /api/finetune/data.
- Add interface for:
  - Model selection (base model)
  - Training parameters
  - Progress tracking (through polling)
- Display live metrics: accuracy, loss, step count.

7. 📈 Monitoring & Analytics
- Charts showing:
  - Query frequency
  - Embedding usage
  - Average response time
  - Token usage (if applicable)
- Display error logs or failed retrievals.
- Show memory usage and disk footprint of embeddings.

8. 👥 User & Auth (Optional)
- Login/signup page
- JWT token handling
- Role-based views (admin, analyst, read-only)

🔗 API Integration Guidelines

Each module should call FastAPI endpoints via a centralized api.ts file:

import axios from "axios";

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || "http://localhost:8000",
});

export const fetchDocuments = () => api.get("/api/documents");
export const uploadDocument = (file: File) => {
  const formData = new FormData();
  formData.append("file", file);
  return api.post("/api/documents/upload", formData);
};
